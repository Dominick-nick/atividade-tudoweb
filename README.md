# Projeto de Pesquisa de Satisfação - Tudoweb

Repositório criado para a entrega da atividade académica de programação em Python, com foco na recolha e análise de dados de atendimento ao cliente.

## 📋 Sobre a Atividade
O programa foi desenvolvido utilizando estruturas de repetição para realizar uma pesquisa de opinião com **50 entrevistados** sobre o atendimento da empresa **Tudoweb**.

O sistema recolhe de cada participante:
* Nome
* Idade
* Opinião sobre o atendimento (1: EXCELENTE, 2: BOM, 3: RUIM)

Ao final de todas as entrevistas, o sistema exibe um resumo com:
* A quantidade total de respostas "EXCELENTE"
* A quantidade total de respostas "RUIM"
